# Ryan Batubara's website

An [Astro](https://astro.build) [Erudite-v2](https://github.com/jktrn/astro-erudite)-based personal site using [MDX](https://mdxjs.com/), [Satteri](https://github.com/bruits/satteri), [Expressive Code](https://expressive-code.com/), [Temml MathML](https://github.com/temml/temml), and [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS).

Some specialized packages, like [abcjs](https://www.abcjs.net/), are also used.

To run do 
```sh
npm install
npm run dev
```
