## How to use components

Within any `.mdx`, import a custom component and pass in the required parameters. Callouts are lighter-weight Satteri directives and need no import:

```mdx
:::important[About callouts]{closed}
  Callouts signify different types of content to the reader
:::
```

Here's how it looks rendered. Notice the `closed` attribute makes the callout closed by default, ideal for e.g. solutions to puzzles.

:::important[About callouts]{closed}
  Callouts signify different types of content to the reader
:::

I can then call out the component as a [hyperlink](#about-callouts). Here's how this line looks in code:

```mdx
I can then call out the component as a [hyperlink](#about-callouts).
```

By default, the callout's `id` is its slugified title, but an explicit directive ID can be supplied too.

## Post-specific components

Almost every post has a custom callout made just for it. For example, here's a music sheet component using [abcjs](https://www.abcjs.net/) with [tablature](https://en.wikipedia.org/wiki/Tablature) support:

<AbcNotation
  abc={`
X:1
M:C
L:1/8
.A, .[AE].[AE]/2 z/2 .[AE].[A^D]/2 z/2 .[A^D].[A^D]/2 z/2 .[A^D].[AE]/2 z/2 |
`}
/>

Sidenote: [abcjs](https://www.abcjs.net/) can actually compile sheets to audio, have the user edit and play sheets, and much more. I've disabled most of these to keep things simple.

Here's a logic grid component for my post [Logic Grids as Data Structures](/blog/logic-grids-as-data-structures):

<LogicPuzzle
  id="example-logic-grid"
  cellSize={30}
  categories={[
    ['Names', ['Amy', 'Bintang', 'Chandra']],
    ['Ages', ['7', '8', '9']],
    ['Birthdays', ['April', 'January', 'September']],
  ]}
/>

It's fully functional and inputs persist even over page reloads.

I want each post to have at least one unique component. I think it adds a lot of interaction and individuality.
