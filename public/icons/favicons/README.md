# Icon Sources

External Markdown links are assigned icons by hostname or selected GitHub
repository in `src/lib/link-icons.ts`. Unmapped links use
`custom-external-link.svg`.

Custom icons use the `custom-*.svg` prefix, Phosphor icons use
`phosphor-*.svg`, and Simple Icons use `simple-*.svg`.

- `phosphor-*.svg`: Phosphor Icons 2.1.1 Fill (MIT)
- `simple-*.svg`: Simple Icons 16.26.0 (CC0-1.0)
- `custom-*.svg`: Custom
